# Проект "Рик и Морти" 

## 📋 О проекте
Интерактивный справочник по персонажам мультсериала "Рик и Морти". 
Проект разработан в рамках учебного задания для отработки навыков работы с React, TypeScript, внешними API и деплоя на GitHub Pages.

## 🔗 Ссылка для просмотра
**Деплой:** [https://ruslan28081991.github.io/RaM/](https://ruslan28081991.github.io/RaM/)

## ⚙️ Функционал
- **Главная страница** — список персонажей с пагинацией (по 20 персонажей на страницу)
- **Карточка персонажа** — отображение имени, статуса, вида и локации
- **Детальная страница** — при клике на персонажа открывается подробная информация:
  - Полное имя
  - Статус 
  - Вид и пол
  - Последняя известная локация
  - Список эпизодов с участием
- **Переключение темы** — светлая/темная (с сохранением выбора)
- **Переключение языка** — русский/английский (с сохранением выбора)
- **Обработка ошибок** — кастомная страница 404 и ErrorBoundary
- **Адаптивный дизайн** — корректное отображение на мобильных устройствах

## 🚀 Запуск проекта локально

### Установка и запуск
```bash
# 1. Клонировать репозиторий
git clone https://github.com/ruslan28081991/RaM.git

# 2. Перейти в папку проекта
cd RaM/vite-project

# 3. Установить зависимости
npm install

# 4. Запустить в режиме разработки
npm run dev
```

## 🛠 Технологии
React — библиотека для интерфейса

TypeScript — типизация

Vite — сборщик проекта

React Router — маршрутизация

Axios — запросы к API

React Query — управление состоянием и кэширование данных

CSS Modules — стилизация компонентов

GitHub Actions — автоматический деплой на GitHub Pages

## 📁 Структура проекта
```bash
vite-project/
├── src/
│   ├── api/          # запросы к API
│   ├── assets/       # изображения, иконки, шрифты
│   ├── hooks/        # кастомные хуки
│   ├── pages/        # компоненты страниц
│   ├── shared/       # переиспользуемые компоненты, константы, TypeScript типы
│   ├── widgets/      # виджеты
│   ├── App.tsx       # корневой компонент
│   └── main.tsx      # точка входа
├── index.html
└── package.json
```

## 🌐 Деплой
Автоматический деплой на GitHub Pages настроен через GitHub Actions.
Достаточно запушить изменения в ветку master — и через 2-3 минуты обновленная версия будет доступна по ссылке выше.
